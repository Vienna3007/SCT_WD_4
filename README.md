# TaskFlow Dashboard 📋

A modern Task Management Dashboard built using HTML, CSS, and JavaScript.

This project provides a professional project-management style interface where users can manage tasks, track progress, assign priorities, and monitor productivity through an interactive dashboard.

---

## 🚀 Live Demo

🔗 https://vienna3007.github.io/Taskflow_Dashboard/

---

## ✨ Features

### Dashboard Features

- Professional Dashboard Layout
- Responsive Design
- Sidebar Navigation
- User Profile Section
- Statistics Cards
- Task Management Table

### Task Management

- Add New Tasks
- Delete Tasks
- Mark Tasks as Completed
- Priority Levels (High, Medium, Low)
- Due Date Tracking
- Assignee Display
- Status Indicators

### Data Persistence

- Local Storage Integration
- Tasks remain saved after page refresh
- Real-time Statistics Updates
